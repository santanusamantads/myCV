SGEMM GPU Kernel Performance & SGD Optimization

From-scratch Stochastic Gradient Descent benchmarking on high-dimensional hardware tuning telemetry.

View GitHub Repository

📌 Project Overview

This project models and predicts GPU kernel execution times using the SGEMM GPU Kernel Performance dataset (241,600 instances, 14 ordinal and categorical kernel parameters)[cite: 2]. Target execution times across 4 independent runs were log-transformed and averaged to stabilize numerical optimization.

⚙️ Methodology & Strategies

Instead of relying on black-box optimization libraries, Stochastic Gradient Descent (SGD) was built completely from scratch using Python and NumPy:

  • Vectorized Cost & Gradients: Custom Mean Squared Error (MSE) loss function along with analytical partial derivatives for weight vectors and bias terms.
  • Strategy 1 (Random With Replacement): Samples mini-batches uniformly with replacement over ⌈N / batch_size⌉ iterations per epoch.
  • Strategy 2 (Random Without Replacement): Shuffles dataset indices randomly at the start of every epoch to iterate through non-overlapping mini-batches.

📊 Hyperparameters & Results

  • Learning Rate ($\alpha$): 0.0005
  • Epochs: 100
  • Batch Sizes Evaluated: 100, 200, 400, 800, 1000, 1600
  • Final Test MSE: ~0.2790 across configurations[cite: 2].
